# RestaurantHub - Modern Restaurant Web Application

A full-featured restaurant ordering and reservation platform built with React and Python Flask backend.

## Features

### Frontend (React)
- ✅ Responsive user interface
- ✅ Menu browsing with filters and search
- ✅ Shopping cart management
- ✅ Secure checkout process
- ✅ Table reservations
- ✅ Order tracking
- ✅ User authentication
- ✅ Profile management

### Pages
- **Home** - Landing page with features and CTA
- **Menu** - Browse dishes with filters
- **Cart** - Manage cart items
- **Checkout** - Order confirmation and payment
- **Reservations** - Book tables
- **Orders** - View order history
- **Profile** - User account management
- **Login/Register** - Authentication

## Installation

### Prerequisites
- Node.js (v14 or higher)
- npm (v6 or higher)

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/ramavaishnavi55-glitch/restaurant-web-app.git
   cd restaurant-web-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open in browser**
   ```
   http://localhost:3000
   ```

## Usage

### User Flow
1. Browse home page
2. Register/Login account
3. Browse menu and add items to cart
4. Checkout and place order
5. Make table reservations
6. Track orders in order history
7. Manage profile settings
